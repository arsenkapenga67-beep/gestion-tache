# Gestion des Tâches - Application Python
Projet Licence 1 - Outils collaboratifs avec Git / GitHub

## Fonctionnalités
- 1 - Ajouter une tâche : demande le titre, refuse si vide
- 2 - Afficher les tâches : affiche avec numéro, ou message si vide
- 3 - Rechercher : demande un mot-clé et affiche les tâches qui le contiennent
- 0 - Quitter : ferme le programme, autre choix = erreur

## Comment exécuter
Ouvrir le dossier dans VS Code, ouvrir main.py, cliquer sur Run Python File.

## Notions utilisées
Variables, liste, conditions, boucle while, fonctions.
